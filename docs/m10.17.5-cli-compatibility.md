## Resolver and operators

The current mode's capability-filtered registry defines unique prefixes.
Later arguments cannot disambiguate an earlier token; exact keywords take
precedence over longer keywords. Examples: `en`, `conf t`, `int g0/0`,
`ip add …`, `no shut`, `sh ip int br`, `sh run`, `sh start`, `wr`.
`co` in privileged EXEC and `ipv6 ro …` in config are ambiguous; use
`ipv6 route` because `router` is also available. On L3 Switch, `ip ro …`
is also ambiguous between `route` and `routing`.

`?` lists roots, `sh?` matches a token, and `show ip ?` lists next tokens.
Tab completes only a unique keyword; otherwise it retains input and lists
candidates. Help does not submit a command or enter history. Ctrl+Z uses xterm
to execute `end` from config mode.

`no` is composed over explicit inverse grammars with `SessionApi.negated`.
It is not embedded in command patterns. Coverage: shutdown, description,
IPv4/IPv6 address, L3 Switch IP routing, management default gateway, IPv4/IPv6 static route,
switchport, access/native VLAN, unused VLAN removal and existing OSPF/BGP/protocol
removals. Address removal retains interface/policies; IPv6 keeps generated
link-local addressing. VLAN 1 and VLANs with dependent access/native/SVI config
are deliberately refused.

One normalizer is shared with config import: G/Gi/Gig/GigabitEthernet,
F/Fa/Fast/FastEthernet, Lo/Loopback, Vl/Vlan, Po/Port-channel, Nve1 and S/Ser/Serial,
case-insensitive. Physical lookup returns an existing exact domain ID. Existing
logical Loopback/SVI/NVE creation rules remain. No Serial medium/profile is added.

Ranges accept `gi0/1-4` and `fa0/1-2, fa0/4`. Description, shutdown,
switchport mode/access/native/allowed VLAN and channel-group preflight every
member before changes. Existing STP/CDP/LLDP range handlers remain available. Other range operations are refused. Trunk allowed VLAN
supports replacement/add/remove.

`do` composes privileged show/ping/traceroute into every config mode and
preserves mode/context. Configuration and navigation commands are excluded.

## Added presentations and limits

Added version/history, individual interfaces, interface status/switchport,
IPv4/IPv6 prefix lookup, IP protocols, IP access-lists, AAA overview,
device event logging, DHCP pools/bindings, OSPFv3 interface/brief and neighbor detail.
Existing OSPF/BGP, discovery, STP/EtherChannel/LACP/PAgP, NAT, management,
MPLS and EVPN/VXLAN retain their domain implementations.

Traceroute uses existing destination reachability and labels the limitation:
TTL hop probes are not modeled, and no intermediate hops are invented.
Logging shows retained simulation device events, not a fabricated syslog buffer.
DHCP bindings expose actual leases.

`copy startup-config running-config` explicitly refuses live merge. Existing
configuration apply reloads a device and cannot implement IOS merge semantics.
Saving, startup inspection and reload preserve the existing lifecycle.
Router IP routing toggles have no persistent Router configuration field (the
existing toggle belongs to the composed L3 Switch routing plane); they remain
L3 Switch commands. Router name-server/domain lookup and speed/duplex remain rejected because
the relevant state is not modeled. M10.18 is not part of this change.

bypass filtering; unrecognized input and credential answers are not retained.
